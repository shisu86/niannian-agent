# 念念 · 演示脚本（5 分钟）

> 目标：让面试官在 5 分钟内看到「人设、记忆、多角色、安全」四件事，而不是看完所有功能。
> 原则：**每一步先说"你要看什么"，再操作；操作后停 2 秒等结果，不要边点边说。**

## 演示前检查

- [ ] 服务已启动：`http://127.0.0.1:8000`
- [ ] `.env` 里 API Key 有效
- [ ] 浏览器缩放 100%，窗口宽度 ≥ 1280（三栏布局）
- [ ] 提前准备两个角色：一个用于主演示（如"妈妈"），一个用于对比（如"小胖"）
- [ ] 准备一段可粘贴的人设对话（见下方附录）
- [ ] 清空演示会话里的测试消息，避免旧记忆干扰

---

## 0. 开场（20 秒，不操作）

> "念念是一个带长期记忆的 AI 情感陪伴 Agent。它做两件事：
> **第一，学习一个具体的人怎么说话；第二，记住你说过的事。**
> 我演示四块：人设、记忆、多角色、安全。"

---

## 1. 人设：从对话里学一个人（60 秒）

**先说什么：** "人设不是让用户填一堆标签，而是粘贴一段真实对话，系统自己提取。"

**操作：**

1. 点左上角「＋ 新会话」→ 弹角色选择器 → 点「＋ 新建角色」
2. 名字填「妈妈」，关系填「母亲」
3. 点「从对话提取人设」→ 粘贴附录里的对话 → 点「提取人格」
4. 展示提取结果：性格、口头禅、价值观、关心方式
5. 改一处（比如把口头禅删掉一条）→ 点「确认使用」

**说什么：**

> "提取和入库之间有一个确认环节——这是 LangGraph 的 interrupt，
> 图停在确认点，用户改完才继续写库。**用户永远有最终决定权。**"

---

## 2. 记忆：它记得你说过的事（90 秒，核心）

**先说什么：** "接下来是重点：记忆不是把聊天记录塞进 prompt，而是抽取成结构化条目。"

**操作（第 1 轮）：**

1. 在输入框说："我最近胃不太好，医生说不让吃辣，下周还要去复查。"
2. 发完后**等 3 秒**（后台在抽取记忆）
3. 指出右侧「这次想起了…」区域 / 打开记忆抽屉（右上角图标）→「记忆」标签页
4. 展示新增条目：类型、重要性、内容

**说什么：**

> "记忆抽取发生在回复之后、图之外。所以用户感觉不到等待，
> 但记忆确实写进去了。可以看到它分成了事实和待跟进两类。"

**操作（第 2 轮，验证检索）：**

1. 新开一句："晚上朋友约我吃火锅。"
2. 展示「这次想起了 2 件事」——胃病和不吃辣被检索出来

**说什么：**

> "这一轮它没有重新问'你胃怎么了'，而是直接命中了两周前的信息。
> 检索用 FTS5 + jieba 分词，本地 2 毫秒，不调模型。"

**操作（第 3 轮，验证时序）：**

1. 说："其实我胃已经好了，医生说可以正常吃了。"
2. 打开记忆抽屉，展示旧条目变成「已取代」（`superseded`）

**说什么：**

> "旧事实没有物理删除，而是标记为被取代。这样保留时间线，
> 也避免'两条互相矛盾的事实同时生效'。"

---

## 3. 多角色：共享事实，隔离情感（60 秒）

**先说什么：** "一个陪伴产品不可能只有一个角色。但多角色的难点不是多加一张表，是**记忆该不该互相看见**。"

**操作：**

1. 左侧点另一个角色（如「小胖」）
2. 说："我下周要去医院复查。"
3. 展示：小胖**知道**"下周复查"（因为这是事实，共享）
4. 再说："我最近跟我妈吵架了，有点难受。"
5. 切回「妈妈」→ 问她："我最近心情怎么样？"
6. 展示：妈妈**不知道**吵架的事（这是情感倾述，属于个人记忆）

**说什么：**

> "规则很简单：客观事实贴冰箱贴，所有角色可见；
> 情感和私事进各自的日记本，只有听你说话的那个人知道。
> 检索条件就是 `本角色记忆 OR 共享事实`。"

---

## 4. 主动关怀（30 秒）

**操作：**

1. 打开设置 → 展示「安静时段」「每日上限」「低落期暂停」
2. （可选）用演示接口触发一条待跟进通知

**说什么：**

> "到点的待跟进会主动弹出来。但它有三道闸：安静时段不发、
> 每天有上限、检测到情绪持续低落就自动降频。**主动不等于打扰。**"

---

## 5. 语音（30 秒）

**操作：**

1. 点「语音回复」开启自动朗读
2. 发一句短消息，听它用角色的音色念出来
3. 说明音色是按角色单独保存的

**说什么：**

> "朗读走 Edge TTS，情绪会影响语速和音调。
> 浏览器自动播放策略会挂起 audio 元素，所以用的是 AudioContext。"

---

## 6. 安全分支（30 秒，必须有）

**操作：**

1. 输入："我不想活了。"
2. 展示：回复停止角色扮演，给出求助渠道；本轮不写记忆

**说什么：**

> "安全不交给模型自由发挥。危机词规则优先，模型再判断一次，
> 还有二次确认防误报。命中后不检索、不写记忆、固定求助话术。"

---

## 7. 收尾：打开开发者视图（20 秒）

**操作：**

1. 点消息下方的「开发者视图」折叠
2. 展示：分支（empathy / normal / safety）、情绪、检索 query、耗时

**说什么：**

> "整个决策过程是可解释的：这一轮走了哪个分支、生成了什么检索词、
> 各节点花了多久，都能看到。评估数据我们也跑了：
> Recall@5 93%，首 token 约 1.1 秒，瓶颈在分析节点，不在检索。"

## 附录：人设提取用的对话

```
妈妈：又不回来？
我：这周加班，回不去
妈妈：行吧，你自己看着办。
我：下周一定回
妈妈：别光说，冰箱里给你留的排骨都冻半个月了
我：知道了知道了
妈妈：知道了就早点睡，别老熬夜
```

## 常见翻车预案

| 情况 | 处理 |
|---|---|
| 模型超时 / 回复失败 | "这轮没回复成功"占位会出现，直接说"降级路径，补一条占位消息，历史不会错位" |
| 记忆抽取还没完成 | 等 3 秒；或打开记忆抽屉刷新，说明"抽取是异步的" |
| 主动关怀没弹 | 检查设置里的安静时段和每日上限，直接展示配置项说明设计 |
| 网络断 | 提前录屏兜底 |
